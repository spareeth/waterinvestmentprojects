# Meeting inputs: Summit Project Portal coordination, Wed 11 Nov 2026, 17:00

## 1. Position (2 minutes)

- The wireframe and note give the right user journey. We can build it as a custom, UAE-hosted portal; the look can differ, the behaviour will match.
- Model we propose to build: project-level permissions, personal logins with two-step verification, no shared passwords, no cross-country browsing, full audit trail, access expiry.
- Proposed timeline: staging demo around 23 Nov, ready for country uploads from about 30 Nov, subject to hosting sign-off. Live through mid-January, then close-out.

## 2. What we add to the wireframe

- Admin "on behalf of" route so the GCFC/BCG team can upload and record approvals where a country prefers not to log in.
- Watermarked viewing, a view-only option for sensitive files (financial models, procurement), virus scanning, file versions.
- Terms of use / confidentiality acceptance at first login.
- A map of accessible projects inside the secure area (not public).
